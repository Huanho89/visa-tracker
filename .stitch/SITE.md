# Site Configuration: US Visa Tracker

## 1. Project Information
- **Title:** US Visa Tracker Sandbox
- **Stitch Project ID:** 11118811530006965458
- **Device Type:** DESKTOP
- **Hosting Theme:** DARK

## 2. Site Vision
A modern, premium platform that allows users to track their US visa application status, receive automated email updates when the Visa Bulletin moves, and access tailored step-by-step guides. The landing page acts as a "Sandbox" where users can instantly check their status without signing up, prompting them to save their profile using Google Auth for automated tracking.

## 3. Sitemap
- [ ] `index` (Landing Page with Sandbox check form and Auth CTA)
- [ ] `dashboard` (Member Dashboard for single case tracking or multi-case switching)
- [ ] `articles` (Guides Directory for NVC fee payment, DS-260, civil documents, etc.)
